Для промышленных предприятий

Водоподготовка и тепло из отходов — для одного предприятия

Экофильтр готовит воду для технологических процессов и котельных. Экомодуль рассчитан на получение тепла из пригодных отходов. Каждое решение проверяется отдельно.

Решения

Вода

Обрабатывает воду на объекте. Железо в воде из скважины — с 0,92 до 0,05 мг/дм³ по протоколу лаборатории.

Тепло из отходов

Установка для получения тепла из пригодных отходов. Опытно-промышленный образец РМ-1 прошёл испытания на безопасность.
