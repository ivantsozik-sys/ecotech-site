# ecotech-site

Корпоративный сайт ЭКОТЕХ — https://ecotechnew.ru. Статический сайт на токенах Дизайн-системы ЭКОТЕХ 2.2 (PRODUCTION FROZEN), без сборщиков и внешних зависимостей. Публикация: push в `main` → проверка в GitHub Actions → сборка в ветку `deploy` → задание по расписанию на Джино раз в 5 минут забирает её скриптом `scripts/jino-pull.sh`. Зарубежный доступ к хостингу не нужен.

## Первый запуск

1. **Репозиторий.** Выгрузить содержимое в `ivantsozik-sys/ecotech-site`, ветка `main`:
   ```bash
   cd ecotech-site
   git remote add origin https://github.com/ivantsozik-sys/ecotech-site.git
   git push -u origin main
   ```
   Если в репозитории уже есть файлы — сначала `git pull origin main --allow-unrelated-histories`.

2. **FTP-аккаунт на Джино** (cp.jino.ru):
   - «Управление → Техническая информация» — технический адрес сервера (вида `j12345678.myjino.ru`).
   - «Управление → FTP-аккаунты» — создать отдельный аккаунт для деплоя.
   - Проверить в файловом менеджере, где лежит корень сайта. Обычно — `domains/ecotechnew.ru/`. Если FTP-аккаунт ограничен сразу каталогом сайта, путь будет `./`.

3. **Секреты GitHub** — Settings → Secrets and variables → Actions:

   | Вид | Имя | Значение |
   |---|---|---|
   | Secret | `FTP_SERVER` | технический адрес из п. 2 |
   | Secret | `FTP_USERNAME` | логин FTP-аккаунта |
   | Secret | `FTP_PASSWORD` | пароль FTP-аккаунта |
   | Variable (необязательно) | `FTP_SERVER_DIR` | каталог сайта, по умолчанию `domains/ecotechnew.ru/`; слеш в конце обязателен |
   | Variable (необязательно) | `FTP_PORT` | порт SFTP, по умолчанию `2222` (SFTP на Джино — те же адрес, логин и пароль, что и FTP) |

4. **Запуск.** Actions → «Деплой на Джино» → Run workflow (или любой push в `main`). Каждый прогон выгружает каталог `dist/` через `lftp mirror`; файлы на сервере не удаляются.

5. **HTTPS.** Сертификат выпущен в панели Джино; перенаправление HTTP → HTTPS включено в `.htaccess` по заголовку `X-Forwarded-Protocol` (27.09.2026). Перенаправление в панели Джино не включать — будет двойное.

## Задание по расписанию на Джино

cp.jino.ru → Управление → Задания по расписанию → добавить задание, периодичность — каждые 5 минут, команда одной строкой:

```
mkdir -p $HOME/ecotech-pull && curl -fsS --max-time 30 -o $HOME/ecotech-pull/pull.sh https://raw.githubusercontent.com/ivantsozik-sys/ecotech-site/deploy/jino-pull.sh && sh $HOME/ecotech-pull/pull.sh
```

Журнал — `~/ecotech-pull/pull.log`. Если каталог сайта не `~/domains/ecotechnew.ru`, добавить в начало команды `SITE_DIR=/путь/к/сайту`.

## Работа с сайтом

- Правка → commit в `main` → проверка и сборка (~1 минута) → на сайте в течение 5 минут.
- Локальный просмотр: `python3 -m http.server 8000` в корне и открыть http://localhost:8000.
- Локальная проверка: `node scripts/check.mjs`.
- Внешние скрипты, стили и шрифты не подключать: проверка не пропустит, а заголовок безопасности (Content-Security-Policy) в `.htaccess` их заблокирует. Встроенные атрибуты `style="…"`, встроенные `<script>` и обработчики `onclick="…"` тоже блокируются — стили только в `assets/css`, скрипты только в `assets/js`; `scripts/check.mjs` это проверяет.

## Что важно знать

- Старые файлы на сервере, которые не выгружались этим деплоем (например, прежний `ecotech_site.html`), **не удаляются** автоматически. Перед первым запуском сделайте резервную копию каталога сайта и уберите лишнее вручную.
- ИСТОРИЧЕСКОЕ: выгрузка по FTP/FTPS (SamKirkland/FTP-Deploy-Action) исключена 27.09.2026 — порт 21 Джино с серверов GitHub недоступен (таймаут). Выгрузка по SFTP (порт 2222) с 27.09.2026 только резервная, вручную: проходит не всегда.
- Цвета, шрифты и отступы — только через `assets/css/tokens.css` по DS 2.2; значения токенов не менять в обход системы.
