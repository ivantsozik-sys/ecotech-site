# ecotech-site

Корпоративный сайт ЭКОТЕХ — https://ecotechnew.ru. Статический сайт на токенах Дизайн-системы ЭКОТЕХ 2.2 (PRODUCTION FROZEN), без сборщиков и внешних зависимостей. Каждый push в `main` выгружается на хостинг Джино по FTPS через GitHub Actions.

## Состав

```
index.html                 главная страница
404.html                   страница ошибки
robots.txt, sitemap.xml    для поисковых систем
favicon.ico                значок сайта (16/32/48 px)
.htaccess                  Apache на Джино: кэш, сжатие, заголовки безопасности, 404, www → без www
assets/
  css/fonts.css            локальные шрифты (@fontsource, SIL OFL 1.1): Manrope, Inter, JetBrains Mono — кириллица и латиница
  css/tokens.css           токены DS 2.2: бренды, тёмная тема, ряд Фибоначчи, шаг кегля ≈ √φ, сетка
  css/site.css             стили страницы
  js/site.js               меню на узких экранах
  fonts/                   16 файлов woff2 (~236 КБ)
  img/logo/                Logo Master v1.1.1: горизонтальный (светлый, тёмный), знак (светлый, тёмный)
  img/                     значки 16/32, apple-touch-icon, og-image.png (превью для ссылок)
scripts/check.mjs          проверка перед выгрузкой: ссылки, ресурсы, якоря, отсутствие внешних ресурсов
.github/workflows/deploy.yml  проверка → выгрузка на Джино
```

## Первый запуск

1. **Репозиторий.** Выгрузить содержимое в `ivantsozik-sys/ecotech-site`, ветка `main`:
   ```bash
   cd ecotech-site
   git remote add origin https://github.com/ivantsozik-sys/ecotech-site.git
   git push -u origin main
   ```
   Если в репозитории уже есть файлы — сначала `git pull origin main --allow-unrelated-histories`.

2. **FTP-аккаунт на Джино** (cp.jino.ru):
   - «Управление → Техническая информация» — технический адрес сервера (вида `j12345678.myjino.ru`).
   - «Управление → FTP-аккаунты» — создать отдельный аккаунт для деплоя.
   - Проверить в файловом менеджере, где лежит корень сайта. Обычно — `domains/ecotechnew.ru/`. Если FTP-аккаунт ограничен сразу каталогом сайта, путь будет `./`.

3. **Секреты GitHub** — Settings → Secrets and variables → Actions:

   | Вид | Имя | Значение |
   |---|---|---|
   | Secret | `FTP_SERVER` | технический адрес из п. 2 |
   | Secret | `FTP_USERNAME` | логин FTP-аккаунта |
   | Secret | `FTP_PASSWORD` | пароль FTP-аккаунта |
   | Variable (необязательно) | `FTP_SERVER_DIR` | каталог сайта, по умолчанию `domains/ecotechnew.ru/`; слеш в конце обязателен |
   | Variable (необязательно) | `FTP_PROTOCOL` | `ftps` по умолчанию; `ftp` — только если FTPS не проходит |

4. **Запуск.** Actions → «Деплой на Джино» → Run workflow (или любой push в `main`). Первый прогон выгружает все файлы, дальше — только изменённые.

5. **HTTPS.** Выпустить бесплатный сертификат в панели Джино, затем включить перенаправление: либо галочкой в панели, либо раскомментировать три строки в `.htaccess` — одно из двух.

## Работа с сайтом

- Правка → commit → push в `main` → через 1–2 минуты изменения на сайте.
- Локальный просмотр: `python3 -m http.server 8000` в корне и открыть http://localhost:8000.
- Локальная проверка: `node scripts/check.mjs`.
- Внешние скрипты, стили и шрифты не подключать: проверка не пропустит, а заголовок безопасности (Content-Security-Policy) в `.htaccess` их заблокирует. Встроенные атрибуты `style="…"` тоже блокируются — стили только в `assets/css`.

## Что важно знать

- Старые файлы на сервере, которые не выгружались этим деплоем (например, прежний `ecotech_site.html`), **не удаляются** автоматически. Перед первым запуском сделайте резервную копию каталога сайта и уберите лишнее вручную.
- На сервере появится служебный файл `.ftp-deploy-sync-state.json` — журнал выгрузки; не удалять (иначе следующий прогон выгрузит всё заново). Доступ к нему снаружи закрыт в `.htaccess`.
- Цвета, шрифты и отступы — только через `assets/css/tokens.css` по DS 2.2; значения токенов не менять в обход системы.

## Содержание: статусы и грифы

| Утверждение на сайте | Статус | Примечание |
|---|---|---|
| Звенигород: железо общее 0,92 → 0,05 мг/л; мутность 9,7 → <1,0; цветность 12 → 3; окисляемость 0,60 → 0,26 мгО/дм³; марганец 0,079 → 0,042 мг/л | ИЗМЕРЕНО | конкретные пробы; требуется подтверждение владельца, что гриф — ОТКРЫТО |
| Энергопотребление Экофильтра 1–2 кВт·ч/м³ | ОЦЕНКА | уточняется на пилоте |
| Выход тепла, выбросы, класс золы Экомодуля | ЦЕЛЕВОЕ | подтверждаются программой испытаний |

Не публикуются: производительность Экофильтра (расхождение 1 м³/ч по акту и 2,5 м³/ч в поздних материалах), экономика Экомодуля, данные площадки заказчика, устройство реактора и алгоритмы (СТРОГО ОГРАНИЧЕНО). Юридическое наименование и реквизиты в подвал не внесены — указать после сверки.
