Как подтверждаются результаты

Для каждого показателя указаны значение, единица измерения, объект, дата, источник и степень подтверждения. Данные заказчиков публикуются только с их согласия.

Статусы

Как читать статусы данных

Статус показывает, на чём основано значение. Стадия готовности решения указана отдельно — на странице каждого решения.

ИЗМЕРЕНО

значение получено по показаниям прибора или лабораторному протоколу и опубликовано

РАССЧИТАНО

рассчитано по измеренным данным или условиям договора

ОЦЕНКА

экспертная или внешняя оценка

ЦЕЛЕВОЕ

задано значение, которого предстоит достичь; результат ещё не подтверждён

ДОПУЩЕНИЕ

принято для модели без подтверждения

ТРЕБУЕТ ПРОВЕРКИ

значение предстоит измерить либо подтвердить по первичному источнику

ИСКЛЮЧЕНО

изъято; не участвует в выводах

ИСТОРИЧЕСКОЕ

заменено более точной или актуальной записью; сохранено в журнале изменений

«Пояснение» в отраслевых таблицах — описание подхода, а не числовой показатель; статус для него не ставится.
